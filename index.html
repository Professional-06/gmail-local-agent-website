Gmail Local Agent

Gmail Local Agent is a desktop application that helps users search their Gmail Promotions category and export matching email content into a PDF report.

How it works

Users sign in through Google's authorization process and choose a time period. The application reads matching emails and creates a PDF report on the user's computer.

Privacy

Gmail access requires the user's authorization. The application is designed to create the PDF locally and does not intentionally send email contents to a separate application server.
